## 1. Имена spec и plan без автоматического commit

**Что изменил**

В имя spec добавил время. В имя plan добавил время и безопасное имя ветки.
После записи spec commit автоматически не создаётся.

**Зачем**

Файлы, созданные в один день, не получают одинаковые имена. По имени plan
видно, для какой ветки он написан, а решение о commit остаётся у пользователя.

**Схема**

```text
Идея
  ↓
Spec с датой и временем
  ↓
Plan с датой, временем и именем ветки
  ↓
Пользователь сам решает, когда делать commit
```

## 2. Предсказуемый запуск сабагентов и отдельного reviewer

**Что изменил**

Добавил единые правила запуска сабагентов в Codex: выбор доступного способа
запуска, понятные имена задач и обязательные роли. Для review используется
отдельный reviewer; если его нельзя запустить как нужно, workflow
останавливается.

**Зачем**

Один и тот же workflow ведёт себя одинаково в разных режимах Codex. Review не
попадает случайному агенту и не зависит от модели текущей сессии.

**Схема**

```text
Workflow выбирает роль
          ↓
Общие правила запуска создают сабагента
          ↓
Отдельный reviewer проверяет результат
          ↓
Ошибка запуска останавливает workflow
```

## 3. Отдельный Spark-workflow только для написания кода

**Что изменил**

Добавил отдельный workflow, который запускается только по прямой просьбе
пользователя. Spark пишет код, а review выполняет отдельный reviewer.

**Зачем**

Spark ускоряет реализацию, но не меняет обычный workflow и не проверяет
собственную работу.

**Схема**

```text
Spark пишет код
      ↓
Reviewer проверяет
      ↓
Исправления
      ↓
Финальная проверка
```
